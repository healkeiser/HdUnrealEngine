# Fog

The **Fog** tab of hdUE Render Settings places UE's Exponential Height Fog in the scene, as an Exponential Height Fog actor does in a level. **Exponential Height Fog** (`unreal:heightFog`) turns it on; **Fog Height** (`unreal:heightFogHeight`, scene units along the stage's up axis) is the actor's height, where the density is Fog Density. Every other parameter is a `UExponentialHeightFogComponent` property (`unreal:heightFog:<Property>`), generated from the engine source with UE's categories, names, ranges and defaults; distances are in UE centimeters, as in UE's Details panel. UE's USD importer imports no fog, so there is no USD schema to follow.

**Volumetric Fog** (`unreal:heightFog:bEnableVolumetricFog`) gives lit, shadowed fog and light shafts: lights scatter into it by their Volumetric Scattering Intensity. UE's Path Tracer renders the height fog only with Volumetric Fog on (`PathTracing.cpp`), and limits its density growth below the fog height with `r.PathTracing.FogDensityClamp`. The fog is part of the scene, so colour AOVs show it too. Changing a fog setting rebuilds the fog, which restarts volumetric fog's temporal history.

## Scene prims for fog, sky and clouds

The height fog, sky atmosphere and clouds can also be placed by prims, as their actors are placed in a UE level, so they live in the scene rather than in the render settings: `UnrealExponentialHeightFog`, `UnrealSkyAtmosphere` and `UnrealVolumetricCloud` (codeless schemas in `resources/generatedSchema.usda`, generated with the same properties as the render settings' tabs, with UE's constructor defaults as fallbacks). Their attributes are the render settings' names: `unreal:heightFog:<Property>`, `unreal:skyAtmosphere:<Property>`, `unreal:volumetricCloud:<Property>`. A prim takes the place of its render settings counterpart (whose switch and properties are then ignored); UE draws one of each, so the first visible prim of a kind by path is used. A height fog's height is the prim's world position along the up axis (its density is Fog Density there), as an Exponential Height Fog actor's Z; a sky atmosphere's position counts only when its Transform Mode places the planet at the component. **hdUE Height Fog**, **hdUE Sky Atmosphere** and **hdUE Volumetric Cloud** (TAB menu > hdUE > Visual Effects) create or edit them, with the render settings' Fog and Sky properties, each at Do Nothing (the prim's fallback, UE's default) until turned on. [render_settings/height_fog_prim](https://github.com/healkeiser/HdUnrealEngine/blob/main/samples/conformance/render_settings/height_fog_prim.usda) checks the fog, its height and that the prim wins over the render settings' fog; [render_settings/sky_atmosphere_prim](https://github.com/healkeiser/HdUnrealEngine/blob/main/samples/conformance/render_settings/sky_atmosphere_prim.usda) the sky and, in realtime, the clouds.

## Local fog volumes

An `UnrealLocalFogVolume` prim is a UE Local Fog Volume: a sphere of fog that fades out radially, combined with a height fog along its up axis. **hdUE Local Fog Volume** (TAB menu > hdUE > Visual Effects, `integrations/houdini/otls/hdue_localfogvolume.hda`) creates or edits one, as Karma Sky Atmosphere does Karma's sky: a primitive path, Houdini's transform section (Uniform Scale is the radius, 1 by default: UE's volume is a sphere of radius 500 cm, scaled uniformly), and UE's properties, each with a control menu. In Create mode every property is authored, at UE's defaults too (Houdini's viewport is not told about an attribute added to an existing prim, so one authored only once changed would not update it); Edit mode changes existing prims ([Houdini](../houdini/viewport.md)). The prim type is a codeless schema shipped with the delegate (`resources/generatedSchema.usda`, generated by `scripts/generate_render_settings.py` from `ULocalFogVolumeComponent`): an Xformable whose attributes are `unreal:localFogVolume:<Property>`, with UE's defaults as fallbacks. The unit sphere of the prim's local space is UE's base volume; its local up axis is the stage's.

As in UE:

- Local fog volumes render in realtime only; UE's Path Tracer ignores them.
- UE draws none nearer than 10 m to the camera (`r.LocalFogVolume.GlobalStartDistance`, in Engine Quality's console variables or as `unreal:cvar:r:LocalFogVolume:GlobalStartDistance`); a volume's own Start Distance can only push it further.
- Height Fog Density 0 hides the whole volume: UE combines the radial and height fog as the product of their coverages (`LocalFogVolumeCommon.ush`), so use a small value for radial fog alone.
- With Volumetric Fog on the height fog, the volumes are also lit and shadowed through it (`r.LocalFogVolume.RenderIntoVolumetricFog`).
