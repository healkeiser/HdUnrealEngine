# Tutorials

Each tutorial produces one result from a scene in `samples/`, with exact values at every step. Start with [Your first render](../getting-started/first-render.md) if you have not rendered with hdUE yet.

## Lighting

- [Lighting a room](lighting-a-room.md): light an interior through its window with sun, sky and a window fill, then by night with an emissive panel.
- [Lumen or the Path Tracer](lumen-or-path-tracer.md): when to use each render mode, where Lumen differs on four scenes, and how to close the gap.

## Image quality

- [Removing noise](removing-noise.md): find the cause of grain, fireflies, blotches, trails or grainy shadows, and the one setting that fixes it.

## Camera and colour

- [Exposure and tone](exposure-and-tone.md): scene-linear or UE's tonemapper, exposure, UE's editor look, and EXRs for comp.
- [Depth of field and motion blur](depth-of-field-and-motion-blur.md): focus and aperture on a row of toys, shutter and motion samples on a moving ball.
