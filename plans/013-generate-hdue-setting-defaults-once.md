## Why this matters

hdUE has 25 settings of its own (`unreal:renderMode`, `unreal:samplesPerPixel`, …). Each default is typed by hand in up to four places: the generator's `HDUE` list (which writes the Houdini UI and the reference docs), every C++ `setting<T>("name", default)` read, the delegate's `GetRenderSettingDescriptors` list, and the hand-written part of `HdUnrealEngine_Viewport.ds`. One has already drifted: **Light Unlit Scenes** (`unreal:autoViewerLight`) is On in the generator, the Houdini UI, usdview and the docs, but Off in the delegate. The hdUE Render Settings LOP authors only values that differ from its default, so with the LOP at its documented default nothing is authored and husk uses the delegate's Off: an unlit scene is lit in the viewport and renders black in husk. Separately, the Houdini menu creates render settings with 64 Path Tracer samples while every other path uses UE's 2048. After this plan, the generator writes one C++ header of defaults, the delegate reads only from it, a unit test fails on any new drift, and the menu-created LOP follows the defaults.

## Steps

### Step 1: Generate `src/hydra/render_setting_defaults.h` from `HDUE`

In `scripts/generate_render_settings.py`, add a function `defaults_header()` that returns the header text for `HDUE`, and a constant `DEFAULTS_HEADER = ROOT / "src/hydra/render_setting_defaults.h"`. `main()` writes it next to `write_light_header(lights)` with `encoding="utf-8", newline="\n"`. Keep it a pure function of `HDUE` so the unit test can call it.

Mapping from `kind` to C++ type:
- `toggle` → `bool` (`true`/`false`)
- `int`, `intmenu` → `int` (the `int64_t` read of `naniteTriangleThreshold` converts implicitly)
- `float` → `double` (format with `repr(float(v))`, so `4.0`, `0.0`)
- `menu`, `string`, `file` → `const char*` (JSON-escape the string with `json.dumps`)

Target output:

```cpp
// Generated by scripts/generate_render_settings.py from its HDUE list: the default of each hdUE setting
// (unreal:<name>), which the Houdini UI, the reference docs and the delegate share. Do not edit.
#pragma once

namespace HdUESettingDefaults {
inline constexpr const char* renderMode = "realtime";
inline constexpr int samplesPerPixel = 2048;
...
inline constexpr bool autoViewerLight = true;
inline constexpr double viewerLightIntensity = 4.0;
...
}  // namespace HdUESettingDefaults
```

The constant name is the setting name (`attribute` without `unreal:`). All 25 are valid C++ identifiers; assert that in the function (`str.isidentifier()`), so a future name that is not fails the generator.

**Verify**: `python scripts/generate_render_settings.py` → exit 0; `git diff --stat` shows the new header and no change to other generated files (the `.ds`, schema, docs, `light_properties.h` must be byte-identical). `grep -c "inline constexpr" src/hydra/render_setting_defaults.h` → 25.
