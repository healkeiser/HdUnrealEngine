Color Grading¶

Temperature¶

Temperature Type¶

Default
White Balance
USD attribute
unreal:postProcess:TemperatureType
Houdini parameter
xn__unrealpostProcessTemperatureType_6sbl

Selects the type of temperature calculation. White Balance uses the Temperature value to control the virtual camera's White Balance. This is the default selection. Color Temperature uses the Temperature value to adjust the color temperature of the scene, which is the inverse of the White Balance operation.

Value Label
TEMP_WhiteBalance White Balance
TEMP_ColorTemperature Color Temperature

Temp¶

Default
6500
Range
1500 to 15000
USD attribute
unreal:postProcess:WhiteTemp
Houdini parameter
xn__unrealpostProcessWhiteTemp_fjbl

Controls the color temperature or white balance in degrees Kelvin which the scene considers as white light.

Tint¶

Default
0
Range
-1 to 1
USD attribute
unreal:postProcess:WhiteTint
Houdini parameter
xn__unrealpostProcessWhiteTint_fjbl

Controls the color of the scene along the magenta - green axis (orthogonal to the color temperature). This feature is equivalent to color tint in digital cameras.

Global¶

Saturation¶

Default
1, 1, 1, 1
Range
0 to 2
USD attribute
unreal:postProcess:ColorSaturation
Houdini parameter
xn__unrealpostProcessColorSaturation_6sbl

Control the intensity of the color(hue) for the entire image.Higher values will result in more vibrant colors.

Contrast¶

Default
1, 1, 1, 1
Range
0 to 2
USD attribute
unreal:postProcess:ColorContrast
Houdini parameter
xn__unrealpostProcessColorContrast_xpbl

Control the range of light and dark values in your scene. Lower values will reduce the difference between bright and dark areas while higher values will increase the difference between the bright and dark areas.

Gamma¶

Default
1, 1, 1, 1
Range
0 to 2
USD attribute
unreal:postProcess:ColorGamma
Houdini parameter
xn__unrealpostProcessColorGamma_1kbl

Control the luminance curve of the scene. Raising or lowering this value will result brightening or darkening the mid-tones of the entire image.

Gain¶

Default
1, 1, 1, 1
Range
0 to 2
USD attribute
unreal:postProcess:ColorGain
Houdini parameter
xn__unrealpostProcessColorGain_fjbl

This value multiplies the colors of the image. Raising or lowering this value will result in brightening or darkening the entire scene.

Offset¶

Default
0, 0, 0, 0
Range
-1 to 1
USD attribute
unreal:postProcess:ColorOffset
Houdini parameter
xn__unrealpostProcessColorOffset_ombl

This value is added to the colors of the scene. Raising or lowering this value will result in the image being more or less washed-out.

Misc¶

Blue Correction¶

Default
0.6
Range
0 to 1
USD attribute
unreal:postProcess:BlueCorrection
Houdini parameter
xn__unrealpostProcessBlueCorrection_krbl

Correct for artifacts with "electric" blues due to the ACEScg color space. Bright blue desaturates instead of going to violet.

Expand Gamut¶

Default
1
Range
0 to 1
USD attribute
unreal:postProcess:ExpandGamut
Houdini parameter
xn__unrealpostProcessExpandGamut_ombl

Expand bright saturated colors outside the sRGB gamut to fake wide gamut rendering.

Film¶

Method¶

Default
Filmic
USD attribute
unreal:postProcess:TonemappingMethod
Houdini parameter
xn__unrealpostProcessTonemappingMethod_gwbl

Controls the method of tonemapping.

Value Label
ETonemappingMethod::Filmic Filmic
ETonemappingMethod::StandardACES Standard ACES

Slope¶

Default
0.88
Range
0 to 1
USD attribute
unreal:postProcess:FilmSlope
Houdini parameter
xn__unrealpostProcessFilmSlope_fjbl

Controls the overall steepness of the tonemapper curve. Larger values increase scene contrast and smaller values reduce contrast.

Toe¶

Default
0.55
Range
0 to 1
USD attribute
unreal:postProcess:FilmToe
Houdini parameter
xn__unrealpostProcessFilmToe_5fbl

Controls the contrast of the dark end of the tonemapper curve. Larger values increase contrast and smaller values decrease contrast.

Shoulder¶

Default
0.26
Range
0 to 1
USD attribute
unreal:postProcess:FilmShoulder
Houdini parameter
xn__unrealpostProcessFilmShoulder_bobl

Sometimes referred to as highlight rolloff. Controls the contrast of the bright end of the tonemapper curve. Larger values increase contrast and smaller values decrease contrast.

Black clip¶

Default
0
Range
0 to 1
USD attribute
unreal:postProcess:FilmBlackClip
Houdini parameter
xn__unrealpostProcessFilmBlackClip_xpbl

Lowers the toe of the tonemapper curve by this amount. Increasing this value causes more of the scene to clip to black. For most purposes, this property should remain 0

White clip¶

Default
0.04
Range
0 to 1
USD attribute
unreal:postProcess:FilmWhiteClip
Houdini parameter
xn__unrealpostProcessFilmWhiteClip_xpbl

Controls the height of the tonemapper curve. Raising this value can cause bright values to more quickly approach fully-saturated white.
